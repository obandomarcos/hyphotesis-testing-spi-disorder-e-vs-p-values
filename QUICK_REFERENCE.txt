💡 KEY INSIGHTS FROM PAPER
─────────────────────────────────────────────────────────────────────────────────

1. Disorder Averaging (§2.3, Eq. 6–9):
   y = A(ω)x + ξ  (random operator)
   ⟹ p(y|x) ≈ N(y; A_eff x, Σ_eff)  (Gaussian approximation)
   where Σ_eff = σ²I + Σ_model
   Effect: Downweights high-disorder directions, improves sampling

2. E-values vs P-values (§4):
   
   P-values (classical):
   • Definition: p = P_H0(T_n ≥ t_obs)
   • Require fixed N (pre-specified sample size)
   • Fail under optional stopping
   
   E-values (modern):
   • Definition: E_n ≥ 0 with E[E_n|H0] ≤ 1
   • Valid under optional stopping (anytime-valid)
   • Don't require exact null distribution
   
   ⟹ E-values enable adaptive measurement (§5d)

3. Sequential Hypothesis Testing (§7.4):
   
   Under H0 (poor reconstruction):
   • Type I error: P(reject H0 | H0 true) → should be ≤ α = 0.05
   • E-value reaches threshold ~45 measurements on average
   • P-value requires fixed N = 200 (4.4× more samples)
   
   Under H1 (good reconstruction):
   • Power: P(reject H0 | H1 true) → target ≥ 0.80
   • E-value stops after ~19 measurements
   • P-value still needs fixed N = 200
   
   ⟹ E-values are more efficient for adaptive measurement
